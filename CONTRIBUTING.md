# Contributing

The DRMD AI Generator is maintained by the Bundesanstalt für Materialforschung und -prüfung (BAM).
BAM publishes the official version in this repository and at
<https://punitharumilli.github.io/DRMD_Generator/>.

## Reporting an error or asking for a change

Please open an issue in this repository, or write to [drmd@bam.de](mailto:drmd@bam.de). Describe
what you did, what you expected and what happened, and give the version shown in the header of
the generator. Never send an API key, and do not send confidential certificates.

BAM reviews every request. Accepted changes are made by BAM in this repository and released as a
new version of `DRMD-Generator.html`.

## Security problems

Please do not report a security problem in a public issue; write to
[drmd@bam.de](mailto:drmd@bam.de) instead.

## Pull requests

Pull requests are welcome; please open an issue first, so that the change can be discussed before
work starts. The source code is in `source/`; `source/BUILD.md` explains how to build and test it.
